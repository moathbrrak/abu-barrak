قراءة روابط قوقل

الروابط المختصرة وقوائم الأماكن يفتحها لك GitHub من حسابك. تسوي مفتاح مرة وحدة بس، ويبقى في جوالك.

  1. افتح صفحة المفاتيح في GitHub.
  2. Token name: اكتب مسار. وفي Expiration اختر أطول مدة.
  3. Repository access: اختر Only select repositories ثم abu-barrak.
  4. Permissions ← Repository permissions: خل Actions على Read and write، وContents على Read-only.
  5. اضغط Generate token، انسخ المفتاح، والصقه هنا.
